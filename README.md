## 🚀 Featured Projects

### 1. VedaAI – AI-Powered Assessment Platform

An AI-powered assessment system that processes printed question papers and handwritten answer sheets, maps questions to answers, evaluates responses using Gemini, and generates marks with detailed feedback.

**Tech:** Next.js, React, TypeScript, Tailwind CSS, Gemini API, PDF.js, Zod.

- [GitHub Repository](https://github.com/ashishvid18/vedaai-assessment)
- [Live Demo](https://vedaai-assessment-tau.vercel.app/)

### 2. Kisan Mitra – AI-Powered Agriculture Platform

An agriculture-focused project combining machine learning and soil-related inputs to support crop recommendations and plant disease detection.

**Tech:** Python, Flask, Machine Learning, Bootstrap, Soil Sensors.

- [GitHub Repository](https://github.com/ashishvid18/KisanMitra)

### 3. News Category Classification – Transformer Based NLP

A Natural Language Processing project using DistilBERT to classify news articles into relevant categories.

**Tech:** Python, DistilBERT, PyTorch, Hugging Face Transformers.

- [GitHub Repository](https://github.com/ashishvid18/news-category-classification-transformer)
